[개인 프로젝트 계획서] 계기판 촬영 기반 차량 경고등 즉시 진단 및 정비 가이드 앱



1. 프로젝트 개요

- 프로젝트명: 위험한 내차? (부제: 계기판 경고등 촬영 진단 및 SOS 정비 가이드)

- 개발자: 컴퓨터소프트웨어학과 (2023136004 / 한희재)

- 개발 기간: 9주차 ~ 15주차 (약 7주)

- 한 줄 요약: 운전자가 계기판 경고등을 촬영하면 AI 이미지 인식으로 경고등을 자동 판별하고, 2차 증상 문진을 통해 위험도 판정 및 가까운 정비소 연결까지 제공하는 앱



2. 문제 인식 및 개발 배경 (Pain Point)

- 갑작스러운 상황에서의 당황: 운전 중 계기판에 생소한 경고등이 점등되면 운전자는 명확한 명칭과 위험도를 몰라 혼란을 겪음.

- 검색의 번거로움: 경고등의 정확한 이름을 모르면 포털 사이트에 "주황색 수위계 모양 경고등"처럼 검색하기 어렵고 정확도가 떨어짐.

- 해결책의 부재: 단순히 경고등 뜻만 알려주면 "지금 당장 차를 세워야 하는지, 정비소까지 운전해서 가도 되는지" 판단하기 어려움.



3. 핵심 기능 (MVP 범위 설정)

(1) 계기판 경고등 자동 인식 (카메라 / OCR·Vision)

- 앱 내 카메라로 계기판 촬영 시 경고등 아이콘 자동 감지 및 식별

- 텍스트 검색 및 카테고리별 경고등 직접 선택(수동 입력) 기능 병행 지원



(2) 위험도 3단계 분류 및 대화형 2차 진단 (문진)

- 위험도 3단계 표시:

  * RED (즉시 정차): 엔진오일 압력, 브레이크, 냉각수 등 (견인 필요)

  * YELLOW (점검 필요): 엔진 경고등, TPMS, ABS 등 (조만간 정비소 방문)

  * GREEN/BLUE (상태 안내): 미등, 하이빔, 크루즈 컨트롤 등 (단순 작동 상태)

- 2차 문진 스텝: "경고등 점등 시 소음이나 진동이 발생하는가?" 등의 Y/N 2차 질문으로 결함 후보 좁히기



(3) 위치 기반 정비소 연동 및 대처 가이드

- 현재 위치(GPS) 기준 반경 내 가장 가까운 정비소/카센터 목록 및 전화 연결 기능

- 경고등별 갓길 정차 후 즉시 조치해야 할 응급 행동 요령 제공



4. 시스템 구조 및 주요 기술 스택

- Frontend (앱): Flutter / React Native ( 또는 Android Studio Java/Kotlin )

- Backend / DB: Firebase (Firestore / Authentication) - 경고등 DB, 정비소 데이터, 사용자 기록 관리

- Image Processing: ML Kit / Teachable Machine / Custom Model - 경고등 아이콘 분류 모델 연동

- API: Kakao Map API / Google Maps API - 위치 기반 정비소 탐색 및 전화 연동



5. 주차별 개발 일정 (9주차 ~ 15주차)

- 9주차 (주제 선정 및 기획): 요구사항 정의서 작성 및 화면 와이어프레임 설계

- 10주차 (DB 구축 & UI 라우팅): 경고등 데이터베이스(이름, 사진, 위험도, 조치법) 설계 및 기본 UI 구현

- 11주차 (카메라 및 이미지 인식 연동): 경고등 분류 모델 학습 및 앱 내 이미지 인식 테스트

- 12주차 (진단 로직 & 위험도 판정): 2차 문진 알고리즘 구현 및 위험도 3단계 시각화 처리

- 13주차 (위치 기반 서비스 연동): GPS 지도 API 연동, 내 주변 정비소 검색 및 전화 걸기 구현

- 14주차 (통합 테스트 & 버그 수정): 전체 유저 플로우 테스트 및 UI/UX 디테일 수정

- 15주차 (최종 시연 & 발표): 프로젝트 최종 결과물 발표 및 결과 보고서 제출



6. 기출 문제 방어 및 기대 효과

- "단순 DB 검색 앱 아닌가요?"

  -> 카메라 이미지 분석 기술과 2차 문진 기반 위험도 판단 로직을 결합하여, 운전자의 검색 단계를 대폭 줄인 실시간 상황 대처형 앱입니다.

- "실제 정비소 데이터는 어떻게 가져오나요?"

  -> 지도 API의 카테고리 검색(카센터/정비소)을 활용하여 GPS 기반 실시간 위치를 연동합니다.
