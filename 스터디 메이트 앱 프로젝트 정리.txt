1. 방향성 전환 (Re-branding)
--------------------------------------------------
* 기존: 학과 공지사항 단발성 확인 및 비동기 기능 테스트 앱
* 변경: 학업 자료(족보) 공유, 스터디 모집, 실시간 Q&A 플랫폼
* UI/UX: Cyber Deep Midnight & Neon Mint 계열의 힙한 다크 모드 적용


2. 주요 기능 구현 및 보완 사항
--------------------------------------------------
[1] 스터디 모집 전용 시스템
  - 스터디 모집 인원 현황 표시 (예: 2/4명, 마감)
  - '스터디 참여하기' / '신청 취소' 버튼 기반 실시간 인원 반영

[2] 검색 및 카테고리 필터링
  - 5개 탭 구획: [전체 / 🔥 시험족보 / 📢 강의공지 / ✏️ 스터디모집 / 🔖 보관함]
  - Custom Chip Container 적용으로 글자 잘림 현상 해결
  - 과목명 및 족보 내용 실시간 키워드 검색

[3] 족보 PDF 첨부 및 다운로드
  - 게시글 작성 시 PDF 요약집 첨부 기능
  - 다운로드 버튼 클릭 시 비동기 처리 및 완료 안내 표시

[4] UI/UX 및 유저 편의 기능
  - 단일 선택 공감 버튼: [❤️, 💡, 🔥, 😢] 중 1개만 중복 없이 선택 가능 (토글 지원)
  - 팝업 규격화: 작성 및 상세 보기 Dialog 크기 고정 (Width 480px, 내부 스크롤)
  - 삭제 및 보관함: 게시글 삭제 기능 및 북마크(🔖) 저장 기능 추가
  - 프로필 모달: 내 정보, 내가 쓴 족보 수, 보관함 저장 항목 확인 가능


3. Flutter 핵심 비동기 개념 반영
--------------------------------------------------
* Future<T> & async/await : PDF 파일 비동기 다운로드 및 네트워크 지연 처리
* Stream<T> (.broadcast()): 상단 시험 D-Day 실시간 타이머 및 다중 구독 에러 방지
* Isolate (compute)       : 게시글 업로드 시 무거운 데이터 파싱을 백그라운드 스레드에서 처리
* setState                : 스터디 참여, 북마크, 공감, 필터링 등 즉각적인 UI 상태 변화 처리
