[개인 프로젝트 계획서]

1. 프로젝트 개요
- 프로젝트명: 위험한 내차? (부제: 초보 운전자를 위한 직관적 경고등 진단 및 조치 가이드)
- 개발자: 컴퓨터소프트웨어학과 (2023136004 / 한희재)
- 개발 기간: 9주차 ~ 15주차 (주 1회 실습 진행)
- 한 줄 요약: 운전자가 계기판의 경고등 모양을 화면에서 선택하면 위험도(🔴/🟡/🟢)와 조치 방법을 직관적으로 안내하고 nearby 정비소 연결을 돕는 앱

2. 문제 인식 및 개발 배경 (Pain Point)
- 경고등 명칭을 모르는 운전자가 검색하기 어려움
- 주황색/빨간색 경고등이 떴을 때 즉시 주행을 멈춰야 하는지 판단이 어려움

3. 핵심 기능 (2학년 맞춤형 MVP)
(1) 직관적인 경고등 아이콘 선택기
  - 명칭 검색 대신 계기판 모양의 아이콘 그리드를 제공하여 터치 한 번으로 선택
(2) 위험도 3단계 분류 및 조치 가이드
  - 🔴 RED (즉시 정차/견인), 🟡 YELLOW (점검 필요), 🟢 GREEN (상태 안내)
  - 1단계 단순 Y/N 질문을 통해 추가 조치 사항 안내
(3) 내 주변 정비소 연결
  - 클릭 한 번으로 외부 지도 앱(카카오맵 등)의 주변 정비소 검색 화면으로 연결

4. 개발 환경 및 스택
- Development: Android Studio (Java/Kotlin) 또는 Flutter
- Data: 앱 내 로컬 JSON / Array 데이터베이스 (경고등 정보 저장)

5. 주차별 개발 일정 (주 1회 기준)
- 9주차: 기획서 작성 및 화면 레이아웃 설계
- 10주차: 메인 화면 및 경고등 선택 UI 구현
- 11주차: 경고등 데이터(이미지, 설명, 위험도) 구축 및 데이터 연동
- 12주차: 상세 진단 화면 및 조건별 조치 가이드 로직 구현
- 13주차: 외부 지도 앱 연동 (정비소 찾기 기능)
- 14주차: 앱 전체 흐름 연결 및 테스트, UI 개선
- 15주차: 최종 프로젝트 시연 및 발표

6. 기대 효과 및 교수님 질의 응답
- "카메라 인식을 안 넣은 이유는?" -> 운전 중 빠른 조치가 핵심이므로, 촬영 오류나 광원 영향 없이 터치 한 번으로 빠르게 진단하는 UX에 집중했습니다.
